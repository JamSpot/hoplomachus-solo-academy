SOLO ARENA · STARTER GUIDE

Learn Remastered solo

Use the game's five modes as distinct ways to practise arena tactics, learn AI behaviour and build confidence.

Rules authority: Use the current Remastered rulebook and official FAQ/errata for setup, AI priorities and edge cases. This page is a route into the rules, not a substitute for them.

Know the five modes

  • Onslaught: face the Immortals and their escalating pressure.
  • Ascension: challenge a Titan.
  • Skirmish: pit a faction against an opposing force.
  • Pandemonium: manage a more chaotic multi-hero contest.
  • Alliance: cooperate with another hero against a shared challenge.

Solo suitability, available opponents and exact setup vary by mode. Confirm the mode's player count, arena, troop/controller setup and win condition in the rulebook before beginning.

First-game approach

  1. Choose one mode and follow its setup section literally.
  2. Separate each troop's chips and identify who controls each unit.
  3. Read the AI targeting priorities before resolving any AI action.
  4. Identify the arena objective and victory condition before planning attacks.
  5. During each turn, check movement, range, line or targeting restrictions, skill timing and status effects as applicable.
  6. After the game, note which decisions created advantage and which units were essential.

Core tactical habits

  • Prioritise the objective, not just the easiest enemy to damage.
  • Use positioning and unit skills together; do not evaluate a unit from its attack value alone.
  • Read the AI priority rules in full. Never substitute intuition for a printed targeting rule.
  • Keep track of crowd favour and mode-specific resources when they affect victory or future choices.
  • Check official clarifications when a skill interaction is ambiguous.

Progression plan

  1. Play one introductory match with frequent rulebook checks.
  2. Repeat the same mode to practise a different tactical approach.
  3. Add a second mode only after you can resolve the first without repeated setup errors.
  4. Use the unit-skill reference sheet and maintain a short list of unresolved rules questions.
