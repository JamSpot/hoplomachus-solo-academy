# Hoplomachus Solo Academy

A growing, source-led solo learning guide for **Hoplomachus: Victorum** and **Hoplomachus: Remastered**, including official expansion content and supported cross-game integration.

## Website
Once GitHub Pages is enabled, the site is intended to publish at:
https://jamspot.github.io/hoplomachus-solo-academy/

## Research principles
- Official rulebooks, component text, official FAQs and errata take precedence.
- Separate confirmed rules from strategy, interpretation and optional house rules.
- Link to sources rather than reproducing proprietary rulebooks or card text.
- Build practical guides early; expand coverage iteratively.
- Test navigation and published builds before calling a release complete.
